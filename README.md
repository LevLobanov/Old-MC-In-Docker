<h1 align="center"><img src="https://minecraft.wiki/images/Icon_Minecraft.png" alt="Minecraft wiki icon" width="48" style="vertical-align: middle; margin-right: 8px;"/> Old mc in docker</h1>

This repo provides dockerfiles and docker compose for fast and easy old mc's servers run.

> [!IMPORTANT]
> Default server.properties files may not work, or may be not complete, since dev continiously update their MCs

There are some server.jar for both BTA and Reindev, but i don't know which versions, they are meant to be backups.
